Gmail module for Axon

This Google OAuth project is used exclusively by Andreas Iskrov for his own Gmail integration.

If you are not Andreas Iskrov and are reading this, please head back; this project is not available for your use.

What it does

The Gmail module connects Axon to the owner’s Gmail account with his permission to search and read messages, detect incoming mail, and create drafts. Email content can be processed by the configured AI service to answer questions and assist with drafting.

The Gmail module requests read-only and compose permissions. Google's compose permission also permits sending, although this module exposes draft creation rather than a send tool.

The Gmail module is code for the Axon framework. This website documents the owner’s personal OAuth deployment, not an email-assistant product or a service offered to other users.
